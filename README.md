# 🚆 Railway Reservation SQL Project

## 📌 Project Overview

This project is a MySQL-based Railway Reservation Database Management System.

The project demonstrates SQL concepts using a real-world railway reservation scenario.

It manages:

- Train information
- Passenger bookings
- Ticket fares
- Booking status

The project contains SQL queries covering filtering, operators, JOINs, GROUP BY, ORDER BY, aggregate functions, and subqueries.
